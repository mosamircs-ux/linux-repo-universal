# AetherOS Core Applications

This directory contains first-party graphical and command-line utilities designed specifically for AetherOS.

## Applications
- **`aether-settings`**: Unified control center managing Display, Appearance, Language/RTL, Network, Bluetooth, Audio, Users, Power, and System Diagnostics.
- **`aether-software`**: Unified software hub integrating APT and Flatpak package management with search, installation, and removal.
- **`aether-updater`**: Dedicated system update manager with automatic Btrfs safety snapshots and one-click rollback.
- **`aether-welcome`**: First-boot interactive setup wizard for onboarding, language selection (Arabic & English), and hardware driver setup.
- **`aether-terminal`**: Terminal emulator profile and wrapper configured with JetBrains Mono and Aether color palette.
