# AetherOS Desktop Environment Layer

This directory contains the Wayland compositor configuration and modular desktop shell components for AetherOS.

## Modules
- **Compositors:** Wayfire (primary 3D effects & smooth snapping) and Labwc (ultra-lightweight fallback).
- **Aether Dock:** Pinned applications, running indicators, orientation configuration (left/bottom), Arabic RTL support.
- **Aether TopBar:** Workspace switcher, window status, unified clock/calendar, notification tray, and quick settings trigger.
- **Aether Launcher:** Fast fuzzy search and categorized application launcher (`Super+A`).
- **Aether Quick Settings:** Slide-out control panel for Wi-Fi, Bluetooth, PipeWire audio, night light, and power profiles.
- **Aether Notifications:** Freedesktop-compliant D-Bus notification daemon with history and Do-Not-Disturb support.
