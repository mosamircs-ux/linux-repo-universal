# AetherOS User Guide

Welcome to **AetherOS Solstice LTS**! This guide introduces the desktop environment, workflow shortcuts, and software management.

---

## 1. Desktop Workflow & Keybindings

AetherOS delivers an intuitive, Ubuntu-inspired desktop workflow with original styling and high-performance Wayland animations.

| Keybinding | Action |
|---|---|
| `Super` or `Super + A` | Open Application Launcher |
| `Super + T` | Open Terminal (`aether-terminal`) |
| `Super + E` | Open File Manager |
| `Super + I` | Open System Settings |
| `Super + Left` | Tile Window to Left Half |
| `Super + Right` | Tile Window to Right Half |
| `Super + Up` | Maximize / Restore Window |
| `Super + L` | Lock Screen |
| `PrintScreen` | Snip / Screenshot Area |

---

## 2. Dock & Quick Settings

- **The Dock:** Left-pinned by default. Right-click any app icon to pin/unpin or customize position via Settings.
- **TopBar Quick Settings:** Click the top-right corner to toggle Wi-Fi, Bluetooth, Night Light, Dark Mode, and adjust audio/mic volume.

---

## 3. Installing Software

Open **Aether Software** from the dock to browse thousands of desktop applications via native APT packages and sandboxed Flatpaks.
