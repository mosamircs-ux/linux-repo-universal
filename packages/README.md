# AetherOS Debian Metapackages & Package Build System

This directory contains Debian packaging source files and recipes for AetherOS components.

## Packages
- **`aether-base`**: Foundational OS metapackage providing systemd tuning, zRAM configuration, audio routing, and networking.
- **`aether-desktop-core`**: Desktop environment metapackage bundling Wayland compositors, shell components, themes, and fonts.
- **`aether-artwork`**: Wallpapers, vector SVG assets, GTK themes, and bootloader branding.
- **`aether-settings`**: GUI & CLI System Settings Center.
- **`aether-installer`**: Bilingual OS installer backend and graphical wizard.
