# AetherOS Artwork & Theming Subsystem

This directory contains original branding assets, vector logos, 4K wallpapers, GTK 3/4 CSS themes, icon theme manifests, Plymouth boot splash, GRUB2 bootloader theme, and Arabic/Latin font configurations.

## Specifications
- **Brand Identity:** Deep Slate & Obsidian with Electric Cyan (`#00D2FF`) and Royal Indigo (`#6366F1`) accents.
- **Typography:**
  - Latin UI: *Inter*
  - Arabic UI: *Cairo* & *Tajawal*
  - Serif: *Amiri*
  - Monospace: *JetBrains Mono*
- **Vector Artwork:** Pure scalable SVG source assets for crisp rendering from 720p to 4K/8K HiDPI screens.
- **Boot Splash:** Smooth Plymouth animation with no mode-flicker on UEFI DRM/KMS.
